## 1. SoundLite 是什麼

SoundLite 把你的**音訊 / 影片檔**自動轉成**文字逐字稿**，並具備：

- **多語言辨識**：中文（繁 / 簡）、English、日本語、한국어，以及 **台語（翻譯成中文）**。
- **說話者辨識（Speaker Diarization）**：自動區分「SPEAKER_01 / SPEAKER_02…」，可自訂名稱。
- **AI 標點強化**：自動補上標點、分段，讓逐字稿好讀。
- **AI 摘要**：一鍵產生重點、待辦事項、關鍵詞。
- **逐字稿編輯器**：邊聽邊改、搜尋取代、自動儲存。
- **多格式匯出與公開分享**：TXT / SRT / VTT / PDF，或產生免登入分享連結。

## 2. 3 分鐘快速開始

1. 前往 https://soundlite.app 並**註冊**（Email 或 Google 皆可）。
2. 登入後進入 **「上傳音檔」** 頁。
3. 把音檔**拖曳**到上傳區，或點擊選擇檔案。
4. 在跳出的**「轉錄設定」**窗選好**任務類型**與**語言**（可先用預設），按確認送出。
5. 送出後可離開頁面去做別的事；轉錄進度會在畫面上即時更新。
6. 完成後會收到通知，點進**任務詳情**即可檢視、編輯、匯出或分享逐字稿。

## 3. 註冊與登入

### 註冊方式
- **Google 帳號（Google OAuth）**
- **Email + 密碼**

註冊即享**免費配額：每月轉錄時長 180 分鐘**。

### 密碼規則
建立密碼時需符合（畫面會即時提示）：
- 至少 **8 個字元**
- 含**大寫**字母
- 含**小寫**字母
- 含**數字**

### Email 驗證
以 Email 註冊後需點擊驗證信中的連結才能啟用。
- 沒收到？可**重新寄送驗證信**（有冷卻秒數），並記得檢查**垃圾郵件**匣。
- 若信件退信 / 被拒收，畫面會出現對應提示。

### 忘記密碼
在登入頁點 **「忘記密碼」** → 輸入 Email → 收信點連結 → 設定新密碼。

## 4. 上傳音檔

進入 **「上傳音檔」** 頁後，可**點擊選擇**或**拖曳**檔案到上傳區。

### 支援格式
- **音訊**：M4A、MP3、WAV
- **影片**：MP4、MOV、AVI（另支援 mkv / webm / flv / wmv）

### 檔案限制
- **單檔上限 3GB**。
- 系統會擋下超過上限的檔案並提示。
- 中途斷線會自動重試。

### 三種上傳方式

| 方式 | 說明 | 條件 |
|------|------|------|
| **單檔上傳** | 選 1 個檔 → 開啟「轉錄設定」窗 | 所有方案 |
| **批次上傳（Batch）** | 選多個檔（一次最多 **10 個**）→ 開啟批次設定窗，可逐檔自訂名稱與標籤 | **Basic 以上方案** |
| **合併音檔（Merge）** | 上傳區右下角三角鈕，把多個音檔合併成**單一任務**（至少 2 檔，合併總大小上限 **200MB**） | 所有方案 |

> ⚠️ Free 方案觸發批次上傳時會跳出升級提示。

### 上傳中的體驗
- 送出後**設定窗立即關閉**，改由畫面上的**全域上傳浮層**顯示進度。
- **可切換分頁 / 離開頁面**而不中斷上傳。
- **同時只允許一個上傳進行中**。
- 完成後跳出成功提示，附「查看」按鈕；若還停在上傳頁會自動導向任務列表。

## 5. 轉錄設定選項

上傳時（單檔設定窗 / 批次設定窗）可設定以下項目：

### 任務類型（二選一）
- **文件（paragraph）**：段落文字 + 標點 + 時間資訊，適合文章、會議筆記、訪談。
- **字幕（subtitle）**：短句分行 + 時間軸，**不加標點**，適合製作字幕。

### 語言
- **自動偵測（預設）**
- 繁體中文 `zh-TW`、简体中文 `zh-CN`、中文（不指定）`zh`
- **台語（翻譯成中文）`nan-TW`**
- English `en`、日本語 `ja`、한국어 `ko`

### 說話者辨識（Speaker Diarization）
- **預設開啟**，自動區分不同講者。
- 可填**預估說話者人數（2–10，可選）**；留空則自動偵測。若已知人數，填入可提高精確度、避免過度切分。

### 標籤（Tags）
- 可自訂輸入（按 Enter 或逗號新增），或從既有標籤**快速選取**，方便日後分類與搜尋。

> AI 標點屬「文件」模式的**自動行為**，無需額外設定。

## 6. 查看處理進度

- **上傳進度**：由全域上傳浮層顯示。
- **轉錄進度**：任務列表 / 詳情頁透過即時串流（SSE）更新，展開任務卡即可看到**百分比進度條**。

### 任務狀態
| 狀態 | 意義 |
|------|------|
| 處理中（processing） | 正在轉錄 |
| 完成（completed） | 可檢視 / 下載 / 分享 |
| 失敗（failed） | 轉錄發生錯誤 |
| 已取消 / 取消中 | 使用者取消 |

- 任務完成或失敗會**跳出通知**。
- **進行中**的任務可按「取消」；**已完成**的任務可查看 / 下載 / 刪除。

### 常見失敗原因
`INVALID_AUDIO`（音檔無效）、`TRANSCRIPTION_FAILED`（轉錄失敗）、`UPLOAD_FAILED`（上傳失敗）、`AUDIO_MISSING`（找不到音檔）、`SERVER_RESTART`（伺服器重啟）、`SYSTEM_ERROR`（系統錯誤）。畫面會顯示對應中文訊息，通常可重新上傳再試。

## 7. 逐字稿檢視與編輯

點進任務進入**詳情頁**，版面為頂部 Header + 左側設定面板 / 右側逐字稿（手機版設定面板改為底部抽屜）。

### 檢視模式
- **文件 / 字幕** 切換。
- 字幕表可調：時間格式、起始時間、時間範圍、內容疏密度（疏鬆 ↔ 密集）。

### 音檔播放器
- 播放 / 暫停、快退 / 快進 **10 秒**、快退 / 快進 **5 秒**。
- 音量、靜音、**播放速度調整（±0.25x）**。
- 若音檔已過期 / 被刪除 / 授權過期，會顯示提示與「重試載入」。

### 邊聽邊對照
- **時間標記**開關：在逐字稿中顯示時間定位。
- 點**時間欄**可跳轉播放位置。
- 按住 **Alt / Option** 移到某句會亮起，點擊即可跳到該句對應的音檔時間。

### 搜尋 / 取代
- 搜尋（上一個 / 下一個、結果計數）、**單筆取代**、**全部取代**。
- 選項：**區分大小寫**、**全字匹配**。

### 編輯與自動儲存
- 切換「編輯 / 完成編輯」模式後可直接修改內容。
- **自動儲存**：狀態列顯示「自動儲存 / 儲存中… / 已儲存 / 儲存失敗，重試中…」。
- 離開有未儲存變更的頁面會提示確認。
- 可直接編輯**任務標題**。

### 講者名稱
- 講者名稱可**自訂**（點講者標籤），支援**全文取代**同一講者名稱。

### 顯示設定
深色模式、字體大小、字重、字體（無襯線 / 襯線）、時間標記、疏密度，皆可個人化。

## 8. AI 摘要

在詳情頁的 **AI 摘要** 區塊：

- 一鍵**生成摘要 / 重新生成**。
- 產出內容包含：**摘要、重點、內容段落、待辦事項、關鍵詞、類型**（會議 / 講座 / 訪談 / 一般）。
- 顯示配額「**本月剩餘 N 次**」，用完會提示。
- 摘要可**一鍵複製**。

## 9. 匯出與分享

### 下載（Download）
- 格式：**TXT、SRT、VTT、PDF**。
- 可勾選要包含的內容：**逐字稿**、**AI 摘要**。
- 可設定：時間格式、疏密度、是否包含**講者資訊**。

### 分享（Share）
- 產生**公開分享連結**，對方**免登入**即可檢視逐字稿（含 AI 摘要）。
- 可**開啟 / 取消**分享、複製連結。
- 連結期限：**永久有效 / 7 天 / 30 天 / 90 天**，可隨時變更。
- 僅**已完成**的任務可分享。

> 🔒 分享連結任何拿到的人都能看，請斟酌內容機敏性再分享；不需要時記得**取消分享**。

## 10. 任務管理與音檔保留

- 在 **「所有任務」** 頁可瀏覽、搜尋、篩選所有任務；側欄「近期」列出最近完成的任務。
- **音檔保留**：音檔會在方案規定的**天數後自動刪除**（逐字稿本身保留）。
  - 可在任務列表**釘選（Pin）**保留音檔，數量受方案上限限制。
  - **最新任務的音檔會自動保留**。
- 逐字稿即使音檔過期仍可檢視 / 匯出，但無法再邊聽邊對照。

## 13. 常見問題 FAQ

**Q：支援哪些檔案格式？單檔多大？**
A：音訊 M4A / MP3 / WAV，影片 MP4 / MOV / AVI（及 mkv/webm/flv/wmv）。單檔上限 3GB。

**Q：上傳到一半可以關掉分頁嗎？**
A：可以。上傳改由全域浮層處理，切換分頁或離開頁面都不會中斷。但**同時只能有一個上傳**進行中。

**Q：可以轉台語嗎？**
A：可以，語言選 **「台語（翻譯成中文）nan-TW」**，會辨識台語並輸出中文。

**Q：怎麼區分不同說話者？**
A：上傳時開啟**說話者辨識**（預設開啟）。若知道人數，填入 2–10 的預估人數可提升準確度。事後可在詳情頁自訂講者名稱並全文取代。

**Q：改了逐字稿要按儲存嗎？**
A：不用，系統會**自動儲存**。狀態列會顯示儲存進度；若儲存失敗會自動重試。

**Q：音檔為什麼不見了？**
A：音檔會在方案規定天數後**自動刪除**（逐字稿保留）。想長期保留請在任務列表**釘選**該音檔。

**Q：分享連結安全嗎？**
A：連結為公開、免登入可看，請自行斟酌內容機敏性。可設定 7/30/90 天或永久期限，不需要時請**取消分享**。

**Q：批次上傳為什麼不能用？**
A：批次上傳為 **Basic 以上方案**功能，Free 方案需升級。

## 14. 鍵盤快捷鍵速查

詳情頁右上角有「快捷鍵」說明可隨時查閱。修飾鍵在 **Windows 為 `Alt`、macOS 為 `Option (⌥)`**。

**需搭配修飾鍵：**

| 動作 | 快捷鍵 |
|------|--------|
| 播放 / 暫停 | `Ctrl + Alt/Option`（同時按） |
| 快退 / 快進 10 秒 | `Alt/Option + ← / →` |
| 播放速度 + / − 0.25x | `Alt/Option + ↑ / ↓` |
| 靜音 | `Alt/Option + M` |
| 跳到某句音檔位置 | `Alt/Option + 點擊句子` |


> 完整清單以詳情頁內建說明為準。
